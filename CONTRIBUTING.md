Contributor Info / Styleguide

For consistency's sake, please follow the PR/style guide outlined below.

- Any new feature must have documentation attached to it.
- File names should only contain A-Z, a-z, 0-9, - and _ (no spaces).
- Any PRs should be able to be explained by a human why they think it would fit/what it fixes as well as any perceived 
issues that might come from the PR.
- Every page needs a level-one heading, all following heading must be level-two or smaller.
